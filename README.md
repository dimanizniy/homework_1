### Задача 2: загрузка информации о фильмах

Программа в `task2/` получает информацию о фильмах по диапазону ID и выполняет запросы параллельно с заданным количеством workers.

Запуск:

```text
go run ./task2 -from 1 -to 10 -workers 5 -timeout 5s
```

Параметры:

- `-from` - ID первого фильма;
- `-to` - ID последнего фильма;
- `-workers` - количество workers;
- `-timeout` - таймаут HTTP-запроса.

Для остановки программы во время работы можно нажать `Ctrl+C`.

### Ветки

- `task-1` - решение задачи 1;
- `task-2` - решения задач 1 и 2.
